## Publicar en GitHub Pages

1. Crea un repositorio público en GitHub (por ejemplo, `daniela-restrepo-qa`).
2. Sube todos los archivos de esta carpeta a la rama `main`.
3. En el repositorio, entra a **Settings → Pages**.
4. En **Build and deployment**, elige **Deploy from a branch**.
5. Selecciona la rama `main`, la carpeta `/ (root)` y guarda.
6. GitHub mostrará la dirección pública cuando termine la publicación.

También puedes usar el repositorio especial `TU_USUARIO.github.io` para que la dirección sea `https://TU_USUARIO.github.io/`.
